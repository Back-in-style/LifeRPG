# 심기체연 인생 게임 — 세부스탯 절대 기준표
 
작성: 2026-11-27 (초기 설정)
 
## 공통 규칙
 
- **기준 집단**: 운동 습관이 있는 20대 한국 남성. 레벨별 분포는 규칙서를 따른다.
| 레벨 | 이름 | 분포 |
|---|---|---|
| 1 | 탈위 | 하위 10% |
| 2 | 반위 | 상위 90~75% |
| 3 | 축위 | 상위 75~50% |
| 4 | 정위 | 상위 50~35% |
| 5 | 진위 | 상위 35~20% |
| 6 | 군위 | 상위 20~10% |
| 7 | 성위 | 상위 10~4% |
| 8 | 극위 | 상위 4~1% |
| 9 | 초월 | 상위 1% 이하 |
 
- **시작**: 13개 세부스탯 모두 1레벨, 스탯 5. 레벨은 특별 퀘스트로만 오른다.
- **측정값이 기준을 넘는 경우**: 측정값이 높아도 시작은 1레벨이다. 승급은 특별 퀘스트로 인정받아서 한다 (이미 4레벨 수준인 체 요소는 승급 퀘스트에서 측정 인증으로 처리할 수 있다).
- **판정 우선순위**: 측정값 > 타이머·기록 > 대화에서 본인이 말한 숫자. 모호하면 한 단계 낮게 판정하고 이유를 적는다.
- **기록이 없는 항목**: 진행자가 대화에서 숫자로 되묻는다. 추정이면 "추정"이라고 표시한다.

## 심
 
### 실행력 — 최근 4주 계획 달성률
 
| 레벨 | 기준 |
|---|---|
| 1 | 20% 미만, 시작해도 며칠 안에 흐지부지 |
| 2 | 20~40%, 쉬운 일만 가끔 해냄 |
| 3 | 40~55%, 일상 루틴은 있으나 새 일은 자주 중단 |
| 4 | 55~70%, 루틴이 안정적이고 새 일도 절반쯤 이어감 |
| 5 | 70~80%, 3개월 이상 이어진 습관이나 프로젝트가 있음 |
| 6 | 80~88%, 6개월 이상 걸린 일을 끝까지 마친 경험 있음 |
| 7 | 88~94%, 1년 이상 걸린 목표를 완수함 |
| 8 | 94~98%, 여러 해 걸린 일을 완수하고 외부 성과가 있음 |
| 9 | 98% 이상 + 남들이 알아보는 장기 결과물 |
 
**판정 방법**
- 달성률 = 완료한 계획 수 ÷ 정한 계획 수. 전날 받은 일일 퀘스트와 본인이 직접 정한 계획 모두 센다.
- 계획은 전날까지 정해진 것만 센다. 사후에 정한 계획은 센다고 보지 않는다.
- 장기 프로젝트는 3개월 이상 걸리고, 남이 확인할 수 있는 결과물(파일, 기록, 공개물)이 있는 일이다.
- 게임 시작 전 기록은 대화로 추정하고 "추정"이라고 적는다.
### 인내 — 힘든 구간 완주율 (최근 4주)
 
| 레벨 | 기준 |
|---|---|
| 1 | 20% 미만, 힘들면 바로 그만둠 |
| 2 | 20~40% |
| 3 | 40~55% |
| 4 | 55~70% |
| 5 | 70~80%, 몸이 힘든 일도 끝까지 마침 |
| 6 | 80~88%, 한계 직전까지 밀어붙이는 일을 정기적으로 함 |
| 7 | 88~94%, 장거리 행군이나 고강도 과정을 중도 포기 없이 마친 경험 |
| 8 | 94~98%, 몇 달 이상 고강도 과정을 버틴 경험 |
| 9 | 98% 이상, 극한 과정을 몇 년 이어감 |
 
**판정 방법**
- **힘든 구간**: 그만두고 싶다고 본인이 말한 구간(운동 마지막 세트, 지루한 공부 분량, 추운 날 야외 활동 등).
- **완주**: 계획한 분량을 줄이거나 중간에 멈추지 않고 끝낸 것.
- 완주율 = 완주한 힘든 구간 수 ÷ 힘든 구간 수.
- **한계 직전**: 운동은 마지막 1~2회가 힘들어서 자세가 무너지기 직전까지, 그 외에는 본인이 "한계"라고 말하는 지점까지.
- **고강도 과정**: 행군, 장기 훈련, 시험 준비처럼 몇 주 이상 이어지는 힘든 과정.
### 절제 — 4주 평균 여가 폰 시간(일) + 충동 행동
 
| 레벨 | 기준 |
|---|---|
| 1 | 8시간 이상 |
| 2 | 6~8시간 |
| 3 | 4~6시간 |
| 4 | 3~4시간, 계획 밖 충동 행동 주 3회 이상 |
| 5 | 2~3시간, 충동 행동 주 1~2회 |
| 6 | 1~2시간, 충동 행동 월 2회 이하 |
| 7 | 1시간 미만, 충동 행동 월 1회 이하 |
| 8 | 30분 미만, 충동 행동 거의 없음 |
| 9 | 필요할 때만 사용 |
 
**판정 방법**
- **여가 폰 시간**: 연락, 일, 공부에 쓴 시간을 뺀 시간. 본인이 말하거나 폰 사용 시간 기록을 쓴다.
- **충동 행동**: 계획 없이 시작해서 30분 넘게 빠진 폰, 영상, 게임, 성적 콘텐츠 같은 행동. 횟수는 대화에서 본인이 말한 것을 센다.
- 두 기준 중 낮은 쪽 레벨을 쓴다.
### 평정심 — 감정이 흔들린 뒤 회복 시간
 
| 레벨 | 기준 |
|---|---|
| 1 | 하루 이상 지속, 주 2회 이상 폭발 |
| 2 | 반나절 |
| 3 | 몇 시간 |
| 4 | 1~2시간, 폭발 월 1회 |
| 5 | 30분~1시간, 폭발 분기 1회 이하 |
| 6 | 10~30분, 압박 상황에서도 말투 유지 |
| 7 | 5분 이내, 갈등 속에서도 판단 유지 |
| 8 | 거의 즉시, 극한 압박에서도 흔들림 없음 |
| 9 | 어떤 상황에서도 평상심 |
 
**판정 방법**
- **흔들림**: 화, 불안, 수치, 우울 등이 올라와서 평소 행동(말투, 식사, 할 일)이 달라진 순간.
- **회복 시간**: 흔들림이 시작된 때부터 평소 행동으로 돌아올 때까지. 본인이 말한 시간을 쓴다.
- **폭발**: 의도하지 않은 큰 소리, 욕, 물건 던지기, 관계를 끊겠다는 말 같은 감정 표출.
- **압박 상황**: 평가, 위계(선임·간부), 갈등, 실수가 들킬 수 있는 상황(당직 근무, 질책, 발표 등).
- **말투 유지**: 목소리 크기와 말 속도를 평소처럼 유지하고, 욕이나 비꼬는 말이 없는 것.

## 기
 
### 지식 — 설명시키기와 독서량
 
| 레벨 | 확인 방법 |
|---|---|
| 1 | 독서 연 0권, 고교 교과 개념을 설명하지 못함 |
| 2 | 고교 교과 일부 개념을 설명, 연 1~2권 |
| 3 | 고교 전 과목 기본 개념을 설명, 연 3~5권 |
| 4 | 대학 1학년 전공 기초(일반화학, 미적분 등) 개념을 설명, 연 10권 |
| 5 | 대학 2학년 전공(유기화학, 열역학 등) 문제를 풀고 개념을 설명, 한 분야 입문서 3권 이상 |
| 6 | 3~4학년 전공 과목을 설명하고 영문 논문 초록을 읽고 요약, 연 30권 |

| 8 | 최신 논문 흐름을 설명하고 논문 게재(박사급) |
| 9 | 국제 학술지 다수 게재, 분야에서 인정받음 |
 
**판정 방법**
- 진행자가 해당 레벨의 개념 3개를 골라 설명을 시킨다. 2개 이상 정확하게 설명하면 그 레벨을 통과한 것으로 본다.
- 독서량은 최근 12개월 기준이고, 책 제목을 말할 수 있는 것만 센다.
- 전공 레벨(4~6)은 화학생물공학 기초를 기준으로 하되, 다른 분야면 같은 난이도의 과목으로 바꾼다.
### 사고력 — 풀 수 있는 문제와 만든 결과물
 
| 레벨 | 확인 방법 |
|---|---|
| 1 | 수능 5등급 이하 문제 풀이 |
| 2 | 수능 4등급 수준 풀이 |
| 3 | 수능 3등급 수준 풀이 |
| 4 | 수능 2등급 수준 풀이, 한 문단으로 논리를 전개 |
| 5 | 수능 1등급 수준 풀이, 근거를 들어 1페이지 주장 글을 씀 |

**판정 방법**
- 진행자가 해당 난이도의 문제를 내거나, 본인이 만든 결과물을 확인한다.
- **논리 전개**: 주장, 근거, 반론에 대한 답이 모두 들어 있는 글.
- **독창적 결과물**: 남의 것을 그대로 쓰지 않고 본인이 설계한 실험, 앱, 글.
- 본인이 만든 결과물은 파일이나 링크로 확인되는 것만 센다.

## 연
 
### 외모 — 관리 6항목 + 외부 반응
 
**관리 6항목 (각 항목은 최근 4주 기준)**
 
| 항목 | 인정 기준 |
|---|---|
| 피부 | 눈에 띄는 트러블이 없고 스킨케어를 꾸준히 함 |
| 체형 | 체지방 18% 이하이고 주 3회 이상 운동 |
| 헤어 | 얼굴형에 맞는 스타일, 최근 6주 안에 정리 |
| 옷 | 상황에 맞는 옷이 3벌 이상 |
| 위생 | 매일 샤워, 치아·냄새 관리 |
| 표정·자세 | 표정과 자세를 의식적으로 연습함 (웃음 연습 포함) |
 
| 레벨 | 기준 |
|---|---|
| 1 | 0~1항목, 외모 칭찬 없음 |
| 2 | 2항목 |
| 3 | 3항목, 가끔 "깔끔하다"는 말을 들음 |
| 4 | 4항목, 외모 칭찬 월 1회 |
| 5 | 5항목, 칭찬 월 2~3회 |
| 6 | 6항목 모두 안정, 칭찬 주 1회, 이성이 먼저 호감을 표현한 경험 |
| 7 | 외부 인정(사진 반응, 연락처 요청이 월 단위로 있음) |
| 8 | 주변에서 연예인급이라고 함 |
| 9 | 직업적으로 인정(모델·연예인급) |
 
**판정 방법**: 외모 칭찬은 본인이 직접 들은 구체적인 말만 센다. "깔끔하네요" 같은 인사치레나 형식적인 말은 제외한다.
 
### 친화력 — 최근 4주 대화 행동
 
| 레벨 | 기준 |
|---|---|
| 1 | 먼저 말 건 적 없음, 단답 |
| 2 | 주 1회 이하 먼저 인사, 3턴 안에 대화 끝남 |
| 3 | 주 1~2회 먼저 말 걸기, 아는 사람과 10분 대화 |
| 4 | 주 3~5회 먼저, 처음 본 사람과 10분 대화 |
| 5 | 매일 먼저 말 걸기, 처음 본 사람과 30분, 유머 성공 |
| 6 | 모임 대화 주도, 갈등 후 관계 회복, 호감을 말로 직접 표현 |
| 7 | 처음 만난 집단에서 중심, 낯선 사람과 연락처 교환 |
| 8 | 집단을 모으고 이끎 |
| 9 | 사람들이 따르는 구심점 |
 
**판정 방법**
- **먼저 말 건 횟수**: 일이 아니라 사람에게 먼저 건 말(인사, 질문, 안부). 본인이 말한 횟수를 쓴다.
- **유머 성공**: 상대가 소리 내어 웃거나 "ㅋㅋ", 맞장구로 반응한 것.
- **호감을 말로 직접 표현**: 간접 멘트나 농담이 아니라 "좋다", "고맙다", "보고 싶다" 같은 직접적인 말.
- **갈등 후 관계 회복**: 다툼이나 어색해진 뒤 먼저 연락하거나 사과해서 다시 편해진 경우.
### 인맥 — 최근 3개월 연락 기록
 
| 레벨 | 기준 |
|---|---|
| 1 | 정기 연락 1명 이하, 속마음 말할 사람 0 |
| 2 | 2~3명, 속마음 0~1명 |
| 3 | 5명, 속마음 1명 |
| 4 | 10명, 속마음 1~2명 |
| 5 | 15명, 속마음 3명, 서로 다른 분야 3곳 |
| 6 | 30명, 도움 요청 가능한 사람 5명 |
| 7 | 50명, 멘토 1명 이상 |
| 8 | 100명, 영향력 있음 |
| 9 | 200명 이상, 분야를 넘는 영향력 |
 
**판정 방법**
- **정기 연락**: 최근 3개월 안에 서로 먼저 연락한 적이 있는 사람.
- **속마음 말할 사람**: 최근 3개월 안에 부끄러운 일이나 감정을 말한 사람.
- **서로 다른 분야**: 직장·학교·취미 같은 서로 겹치지 않는 사회 집단.
- **도움 요청 가능한 사람**: 곤란할 때 부탁하면 들어줄 것이라고 본인이 말할 수 있고 실제로 부탁한 적이 있는 사람.
- **멘토**: 진로나 일에 대해 정기적으로 조언을 듣는 윗 사람.
