## 0. 규칙서 → 게임 요소

| 규칙서 | 구현 |

| 주요 요소 레벨 = Σa²/Σa | `elementLevel()` (소수 표시) |

| 일일 = 주요 요소 레벨 기준 스탯 5% 분배, 주간 = 3배 | 퀘스트 생성 시 보상 확정 (`weights` × 총량) |
| 일일 상한: 주요 요소당 하루 2개 (최대 8), 주간 제외 | `addQuest`/가져오기 시 검사 |

| 경고: 기한 안 조건(n일 중 m일) 충족 시 해제, 실패 시 벌칙·스킬 삭제 | `Quest.kind=warning`, 체크인, 롤오버 판정 |
| 스킬 = 자리잡은 습관 | `Skill` (연속 경고 실패 2회 → 삭제) |
| 운영: 대화 1 + 분석 4 에이전트 → 통합 파일 → 게임 업데이트, 브리핑 추출 | `claude/` 에이전트 키트, 업데이트 JSON 가져오기, 상태 JSON·브리핑 MD 내보내기 |

## 1. "아직 정할 것" — 기본안 (모두 `sgcy_config.dart` 상수로, 나중에 바꿀 수 있음)

| 항목 | 기본안 |
|---|---|
| 주요 요소 레벨 소수 | 표시는 소수 1자리, **보상 기준은 버림** (보수적) |
| 9레벨 기준 스탯 / 일일 보상 | 1,000만 / 50만 (5레벨부터의 10배 규칙 연장) |
| 자연 감소 기준 | 세부스탯 **자기 레벨**의 기준 스탯 |
| 경고 발동 | 판단은 분석 에이전트 몫(규칙서 제안: 1회 기록, 1주 2회 반복 시 발동)을 에이전트 지침에 명시 |
| 경고 벌칙 단계 | 경미 1배 / 보통 3배 / 심각 5배 (일일 보상 기준), 심각은 연결 스킬 즉시 삭제 |
| 경고 해제 조건 | 기본 5일 중 4일 체크인 |
| 스킬 획득 | 특별 퀘스트 보상. 습관형은 "30일 중 24일" 체크인 특별 퀘스트로 표현 |
| 스킬 삭제 | 연결된 경고 퀘스트 2번 연속 실패 |
| 상태 파일 형식 | JSON (`sgcy-state` v2) + 업데이트 JSON (`sgcy-update` v1) + 브리핑 Markdown |
| 기존 생활 비서와 통합 | 범위 밖 |
| 초기 배치 | 전 세부스탯 1레벨·스탯 5로 시작. 업데이트 JSON의 `placements` 또는 앱에서 직접 배치 |
